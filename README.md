# 🚀 My Portfolio Website

Welcome to my frontend portfolio repository! This project was built using Next.js and Tailwind CSS, featuring impressive animations powered by Framer Motion.

## 🎨 Desain UI/UX

Before the coding phase, the project was first designed using Figma. You can view the complete blueprints, components, and layout via the link below :
👉 \*\*[Click here to open the Figma design] : (https://www.figma.com/design/St7L3UrO1MbNedzDFH4OCl/Portfolio-2---REP?node-id=8411-143671&p=f&t=SxWzu82YC2uPPvxn-0)

# 📖 About

This project is a **Slicing Figma to Website Challenge**.

The goal is to convert a modern portfolio UI from Figma into a production-ready website while maintaining:

- Pixel Perfect Layout
- Responsive Design
- Clean Code Architecture
- Smooth Animation
- Reusable Components
- SEO Friendly
- Deploy Ready

# 📦 Installation

Clone repository

```bash
git clone https://github.com/JamesBangguna/frontend-portfolio.git
```

Go to project

```bash
cd frontend-portfolio
```

Install dependencies

```bash
npm install
```

Run development

```bash
npm run dev
```

Open

```
http://localhost:3000
```
